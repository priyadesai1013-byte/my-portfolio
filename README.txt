HOTEL MANAGEMENT SYSTEM — SEPARATE SOURCE FILES

Files:
- index.html: page structure and hotel room/booking content
- style.css: layout, colors, responsive design
- script.js: booking validation, cost calculation, and demo records

How to run:
1. Keep all three files in the same folder.
2. Open index.html in a web browser.
3. Internet is needed for the remote hotel photos.

Note: This is a front-end student demo. It does not connect to a real hotel, database, or payment service.
