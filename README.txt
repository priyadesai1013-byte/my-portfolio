# Personal Portfolio Website

## Project Overview
This project is a personal portfolio website developed using HTML, CSS, and JavaScript. It showcases personal information, technical skills, projects, and contact details. The website is deployed online using GitHub Pages.

## Objectives
- To create a personal portfolio website.
- To design a responsive and user-friendly interface.
- To learn how to upload website files to GitHub.
- To deploy a website using GitHub Pages.
- To make the website accessible through a public URL.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- GitHub
- GitHub Pages

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Explore the portfolio sections.

## Deployment Using GitHub Pages
1. Create a repository on GitHub.
2. Upload all portfolio files to the repository.
3. Open the repository Settings.
4. Select Pages from the sidebar.
5. Choose Deploy from a branch.
6. Select the `main` branch and `/(root)` folder.
7. Click Save.
8. Wait for deployment to complete.
9. Open the published website URL.
